# 推文结构公式

> 已验证的推文结构模板，写推文时直接套用。
> 随着数据复盘不断更新。

---

## 1. 认知冲突型

```
[大多数人以为 X]
但实际上 [反直觉的事实 Y]
[一句话解释为什么]
```

示例框架：
```
90%的人以为 [常见认知]
实际上 [反转]
因为 [底层逻辑]
```

## 2. 数据+洞察型

```
[一个具体数据]
大多数人看到的是 [表面结论]
但真正值得关注的是 [深层洞察]
```

示例框架：
```
[数字] + [事实]
这意味着 [洞察]
而 [更深一层的思考]
```

## 3. 个人经历型

```
[我做了什么]
结果 [发生了什么]
学到一件事：[认知升级]
```

示例框架：
```
[时间/场景] 我 [做了X]
[意外的结果]
[一句话总结，不说教]
```

## 4. 金句型

```
[一句话，短、狠、准]
```

要求：不超过两句话，能独立传播，不需要上下文。

## 5. 提问型

```
[一个好问题]
[给出一个反直觉的思考方向，但不给答案]
```

注意：不要超过推文总量的15%，太多显得没主见。
