# 对标方法论（dontbesilent）

## 一句话定义
找到一个有利润的、你能看懂的、你能模仿的生意，复制动作，复制收益——不需要真正理解这个生意。

## 核心框架

### 好的对标标准
1. 这是一个有利润的生意（是利润，不是收入）
2. 你能看得懂这个生意
3. 你能模仿这个生意

### 不好的对标（常见误区）
- 因为是兴趣爱好 → 做
- 因为是大学专业 → 做
- 因为个性气质匹配 → 做
- 因为行业风口/热点 → 做
- 因为朝阳产业 → 做

**核心逻辑：** 这些筛选条件只会阻碍你看待生意的开放性。如果你只做10%能力范围内的事，再挑三拣四筛掉90%，只剩1%可做。

### 去哪里找对标
- 去**内容平台**找（小红书/抖音/快手/微博/视频号/公众号），不去电商平台看
- 原因：内容平台能看到完整的获客链路——怎么做内容、怎么运营、怎么引流、评论区怎么互动
- 电商平台（淘宝/拼多多）看到销量1w+，无法倒推有效获客信息

### 对标分析四步法（案例：小红书挂历商家）
1. **收入预估**：已购人数 × 单笔毛利 → 半个月2万
2. **货源验证**：30秒判断货的问题能不能解决（拼多多识图找货源）
3. **定位流量来源**：翻阅视频找规律——大多数个位数点赞，极少数爆款500+，2-3个视频在真正吸引流量
4. **特殊细节**：每半小时发一条视频 → 虽然违反常规运营逻辑，但人家拿到结果了

## 关键洞察

### 事实优先法则的最佳案例
> 「以我过往的运营逻辑，我不会推荐任何人这么做，但是既然他们拿到结果了，如果我要对标的话，我会模仿这个行为。这也说明，在不断模仿对标的过程中，我们的认知会飞速成长。」

这就是"当认知与事实冲突时，选择事实"的活教材：
- 你觉得每半小时发一条是错的 → 但人家半个月赚2万
- 理性选择：先模仿，再理解

### 开放心态 + 高执行力
> 只有完全开放的心态+极高的执行力，才能对抗「我是小白我什么都不懂」这个缺陷。

殡葬、宠物美容、太空探测、手工蜡烛、深海采矿、婚礼策划、昆虫养殖、古董钟表、啤酒酿造、气象预报……任何行业都要愿意一头扎进去。

## 使用场景
- 写"认知局限性"相关推文时的核心案例
- 讨论创业/副业选择时的方法论
- "事实优先法则"的实战佐证
- 反驳"做自己擅长的事"这类鸡汤

## 相关金句
- 「模仿一个你看不上但有效果的东西，比坚持一个你认为正确但没结果的东西有价值得多」
- 「裸辞创业找专业对口的生意，进度不是0%，是负50%」
- 「不需要真正理解一个生意，复制动作就能复制收益」
