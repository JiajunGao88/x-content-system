# Skill: 检索素材库

## 触发条件
用户说"找素材"、"检索素材"、"有没有写过"、"相关内容"等

## 核心规则
- 按优先级检索：核心概念 → 金句 → 爆款推文 → 已发布内容
- 返回结果要具体，不要只说"找到了"，要展示内容摘要
- 如果没找到，明确说"素材库中没有相关内容"

## 工作流程

1. 解析用户的检索意图（关键词/主题/情绪）
2. 依次检索以下目录：

| 优先级 | 目录 | 检索内容 |
|--------|------|----------|
| 1 | `02-内容素材库/核心概念库/` | 理论框架、方法论 |
| 2 | `02-内容素材库/金句库/` | 高质量表达 |
| 3 | `02-内容素材库/爆款推文库/` | 已验证的推文结构 |
| 4 | `01-内容生产/已发布/` | 已发布的内容 |
| 5 | `02-内容素材库/灵感碎片/` | 未整理的原始素材 |

3. 返回格式：
```
📂 找到 X 条相关素材：

1. [来源目录] [文件名]
   摘要：[相关段落摘要]
   复用建议：[怎么用到当前需求]

2. ...
```

4. 如果没找到：
```
素材库中没有直接相关的内容。
建议：
- 可以从 [角度] 新写
- 写完后建议入库到 [具体目录]
```
