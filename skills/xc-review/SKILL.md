# xc-review：数据复盘（个人内容层）

> 属于个人内容层（`xc-*`）。对应宪法核心原则 4「数据驱动」。

## 触发条件
用户说"记录数据"、"复盘"、"这条推文表现怎么样"等。

## 核心规则
- 数据记录到 `04-数据复盘/发布数据记录.md`。
- 每条记录含：内容摘要、数据、分析。
- 定期（周/月）做趋势分析，结论写回 `03-方法论沉淀/`。

## 工作流程

### 单条数据记录
用户提供数据后追加到 `发布数据记录.md`：
```markdown
---
### [日期] [推文前10字…]
- 类型：[认知冲突/数据洞察/个人经历/金句/提问]
- 平台：[X / 小红书]
- 展示量：[数字]
- 互动量：[点赞/转发/评论/书签]
- 互动率：[互动量/展示量]
- 推文内容：[完整内容]
- 分析：表现好的原因 / 表现差的原因 / 下次改进
```

### 周/月趋势分析
用户说"周复盘""月复盘"时：①读该时段全部记录 ②分析：哪种类型表现最好？互动率最高/最低的 3 条为什么？发布时间有无影响？③输出改进建议，更新到 `03-方法论沉淀/` 相关文件。

### 爆款入库
某条互动率 > 平均值 2 倍：自动建议入库 `02-内容素材库/爆款推文库/`（用 `/xc-save`），分析爆款原因，提炼可复用结构。

## 与 dbskill 衔接
- 复盘出的高价值结论/否决方向，想跨对话长期跟踪 → `/dbs-save`（攒多份）→ `/dbs-report`（合并成报告）。
- 复盘发现某条规律值得做成长期决策资产 → `/dbs-decision`。
