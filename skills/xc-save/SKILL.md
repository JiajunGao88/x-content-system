# xc-save：素材入库（个人内容层）

> 属于个人内容层（`xc-*`）。对应宪法核心原则 2「素材优先」的供给端——把好东西沉淀成可复用资产。

## 触发条件
用户说"入库"、"存金句"、"存概念"、"这个表达很好"等。

## 核心规则
- 分清类型，存到正确目录。
- 金句库按主题分文件，不堆在一个文件里。
- 核心概念写清定义 + 使用场景。
- 爆款推文标注数据和爆款原因。

## 素材分类与存储

### 金句 → `02-内容素材库/金句库/[主题].md`
```markdown
> [金句内容]
- 来源：[原创/引用自谁]
- 使用场景：[什么主题的推文适合用]
- 入库日期：[日期]
```

### 核心概念 → `02-内容素材库/核心概念库/[概念名].md`
```markdown
# [概念名称]
## 一句话定义
[最简单的话说清]
## 详细解释
[2-3 段]
## 使用场景
- 写 [主题] 的推文时引用；适合 [认知冲突/数据洞察] 类型
## 相关金句
## 入库日期：[日期]
```

### 爆款推文结构 → `02-内容素材库/爆款推文库/[编号]-[主题].md`
```markdown
# 爆款推文：[主题]
## 原文
## 数据表现（展示量/互动/互动率）
## 爆款分析（类型 / 成功原因 / 可复用的结构）
## 入库日期：[日期]
```

## 注意事项
- 不要什么都存，只存真正好的。
- 金句库每主题文件 ≤30 条，超了筛选精简。
- 核心概念库是"思想武器库"，质量 > 数量。

## 与 dbskill 衔接
- 沉淀的概念若需拆到原子级、检验是否成立 → `/dbs-deconstruct`。
- 想把整批旧内容做成结构化资产工程（内容单元/主题地图/选题装配）→ `/dbs-content-system`。
