# Skill: 素材入库

## 触发条件
用户说"入库"、"存金句"、"存概念"、"这个表达很好"等

## 核心规则
- 分清素材类型，存到正确的目录
- 金句库按主题分文件，不要全堆在一个文件里
- 核心概念要写清定义 + 使用场景
- 爆款推文要标注数据和爆款原因

## 素材分类与存储

### 金句 → `02-内容素材库/金句库/[主题].md`
```markdown
> [金句内容]
- 来源：[原创/引用自谁]
- 使用场景：[什么主题的推文适合用]
- 入库日期：[日期]
```

### 核心概念 → `02-内容素材库/核心概念库/[概念名].md`
```markdown
# [概念名称]

## 一句话定义
[用最简单的话说清楚这个概念]

## 详细解释
[2-3段展开]

## 使用场景
- 写 [主题] 的推文时可以引用
- 适合 [认知冲突/数据洞察] 类型的推文

## 相关金句
- [如果有的话]

## 入库日期：[日期]
```

### 爆款推文结构 → `02-内容素材库/爆款推文库/[编号]-[主题].md`
```markdown
# 爆款推文：[主题]

## 原文
[完整推文内容]

## 数据表现
- 展示量：[数字]
- 互动：[点赞/转发/评论]
- 互动率：[百分比]

## 爆款分析
- 类型：[认知冲突/数据洞察/...]
- 成功原因：[1-2句]
- 可复用的结构：[提炼出的模板]

## 入库日期：[日期]
```

## 注意事项
- 不要什么都存，只存真正好的
- 金句库每个主题文件不超过30条，超了就筛选精简
- 核心概念库是"你的思想武器库"，质量 > 数量
